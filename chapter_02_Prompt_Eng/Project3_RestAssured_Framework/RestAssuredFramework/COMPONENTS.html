📊 Test Execution Flow

1 TestNG launches test suite (testng.xml)
↓
2 @BeforeClass setup() - Initialize AuthClient/HealthClient
↓
3 @Test method executes - Call client.authenticate()/ping()
↓
4 Client builds RequestSpecification via RequestSpecificationBuilder
↓
5 REST-Assured sends HTTP request to API
↓
6 API responds with data (POJO deserialization via Jackson)
↓
7 ResponseValidator validates status code and payload
↓
8 LoggerUtil logs results (success/failure)
↓
9 @AfterClass tearDown() - Cleanup resources
↓
10 Report generated (TestNG HTML, Allure)
